# Структура проекта RolsTraker

Проект состоит из двух основных частей: **локального C++ клиента** (самого трекера), который работает на ПК пользователя, и **веб-сервера (Cloudflare Worker)**, который принимает данные и отображает их на публичном сайте.

## ⚙️ Как работают потоки программы (Архитектура)

Так как программа должна одновременно рисовать интерфейс, качать файлы и опрашивать сервера Riot, она разбита на несколько независимых параллельных потоков внутри `main.cpp`:

1. **Главный поток (UI Thread):** 
   Работает в `main()`. Рисует консольный интерфейс через библиотеку FTXUI (`screen.Loop(renderer)`). Перехватывает движения мыши, скроллинг и клики.
   
2. **Поток опроса игры (Polling Thread):** 
   Крутится в фоне. Раз в 3 секунды проверяет статус Valorant, делает запросы к локальному Riot Client, тянет фазу матча, обновляет ранги и имена игроков.

3. **Поток синхронизации с сайтом (Pusher Thread):** 
   Функция `runDataPusher`. Раз в 2 секунды берет текущие данные матча из памяти (безопасно через `g_mutex`) и отправляет их POST-запросом на твой Cloudflare Worker.

4. **Потоки статистики (Fetch Threads):** 
   Функция `fetchPlayerStats`. Когда ты кликаешь на нового игрока, создается временный независимый поток, который выкачивает его историю матчей в фоне (чтобы не зависал интерфейс). Как только данные скачаны, поток сохраняет их в `g_statsCache` и завершается.
